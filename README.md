# BUY — customer web app (React)

Mobile-only React (Vite) build of the BUY customer storefront, demoed with a clothing shop (Urban Threads BLR).

Screens: Home (category tabs, cart pill), Product Details (variants + bulk packs), Cart, Saved Addresses,
Address form, Payment, Order status, My Orders, My Refunds + refund details, Store Details, More sheet.

```bash
npm install
npm run dev      # http://localhost:5530
npm run build    # outputs dist/
```

Store, categories, products and offers live in `src/data.js`. Product photos: Unsplash (free license).
